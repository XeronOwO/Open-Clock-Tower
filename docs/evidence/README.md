# evidence/ — 交付证据

本目录放两样东西：**交付前要逐行核对的清单**，和**什么才算证据的判据**。

| 页面 | 内容 |
|---|---|
| [delivery-checklist.md](delivery-checklist.md) | 交付清单；一行一行勾，每行必须写出该行的证据 |
| [verification.md](verification.md) | 什么样的一段文字才配叫证据；证据放哪；先红后绿怎么记 |

## 两条最容易违反的

1. **禁止批量勾选。** 某一行的勾选若指不出具体证据，它就是没勾。
2. **纸面审查 = 没审查。** 读代码读出来的"应该没问题"，不是证据。
