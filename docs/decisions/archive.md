# 已归档决策

> 被推翻的决策移到这里。**不删除**——"当初为什么那么选"是后来的读者最需要的信息之一。
> 归档条目必须写明**被哪一条取代**（`Superseded by D-nnnn`）。

## 归档格式

```markdown
## D-nnnn 标题

- **状态**：Superseded by D-nnnn（日期）
- **当初的选择**：……
- **当初的代价**：……
- **为什么被推翻**：是什么事实变了 / 当初漏掉了什么
- **留下的教训**：这条归档对后来的人有什么用
```

「留下的教训」不是客套：一条决策被推翻时，真正值得记的是**当初的判断在哪一步偏了**。
