本目录放**本项目自己的取舍**：做什么形态、用什么技术、接受什么代价。

| 页面 | 内容 |
|---|---|
| [index.md](index.md) | 决策一览表 + 与「裁定」的分工 |
| [active.md](active.md) | 生效中的决策全文（背景 → 选项 → 选择 → 代价） |
| [archive.md](archive.md) | 被推翻的决策，写明被谁取代与留下的教训 |

## 与「规则裁定」的区别

| | 决策 `D-nnnn` | 裁定 `R-nnnn` |
|---|---|---|
| 管的是 | **我们**的选择 | **游戏**的规定 |
| 载体 | 本目录 | `../standard/rulings.md` |
| 改主意 | 新增一条，旧的标 `Superseded by` | 改裁定 **+ 补回归测试** |
| 使用者的态度 | 可以提意见改 | 必须遵守 |

放错地方会让"这是游戏的规定"和"这是我们的偏好"分不清——两者对说书人的含义完全不同。
