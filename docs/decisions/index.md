## 与「裁定」的分工

- **决策（Decision）**：本项目**自己的**取舍——用什么数据库、做成什么形态。改主意只需新增一条决策。
- **裁定（Ruling）**：**游戏规则**层面的未确证之处——三角色相克怎么算。改主意要改 `docs/standard/rulings.md`
  并同时补回归测试。

两者不可混放：把规则争议写进决策表，会让"这是游戏的规定"和"这是我们的选择"分不清。
