# 梦殒春宵角色范例清单（回归测试登记）

> 本页回答一个问题：**每个《梦殒春宵》角色有哪些百科范例要变成回归测试。**
> 来源：各角色页「范例」节，钟楼百科 2026-10-01 抓取（层级 3，见 `sources.md` §2）。
> **本页只登记，不实现**：实现时在 `tests/Kernel.Tests` 建用例，并回来补上实际用例名。
> 范例与「规则细节」（L1）或规则页（L2）冲突时，以后者为准，并登记 `rulings.md`。
> 用例名格式 `TC-<slug>-<两位序号>`，编号即登记顺序。

## 镇民（13）

### 钟表匠 `clockmaker`
来源：百科《钟表匠》· 2026-10-01 抓取 · 范例

| 用例 | 场景（百科范例） |
|---|---|
| `TC-clockmaker-01` | 方古坐在麻脸巫婆旁边。钟表匠得知了“1”。 |
| `TC-clockmaker-02` | 诺-达鲺顺时针方向依次坐着筑梦师、舞蛇人，然后是镜像双子。诺-达鲺逆时针方依次坐着畸形秀演员、心上人、哲学家、贤者，然后是女巫。因为女巫与恶魔的距离为五，而镜像双子与恶魔的距离为三，所以钟表匠得知了“3”。 |
| `TC-clockmaker-03` | 方古与两名旅行者相邻，一善一恶。洗脑师与其中一名旅行者相邻。在第一个晚上，钟表匠得知了“2”，因为邪恶的旅行者不是爪牙。 |

| `TC-dreamer-02` | 筑梦师选择了一名获得了卖花女孩能力的哲学家。筑梦师得知该玩家要么是哲学家，要么是亡骨魔。 |

| `TC-dreamer-04` | 筑梦师选择了一名玩家，他的真实角色是涡流。因为涡流的能力效果，筑梦师获得的信息必须是错误的。所以筑梦师得到这个玩家的角色是神谕者或诺-达鲺。 |
