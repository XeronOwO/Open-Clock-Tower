# 梦殒春宵角色规则清单（实现依据）

> 本页回答一个问题：**实现《梦殒春宵》某个角色时，规则依据有哪些、从哪里查得到。**
> 数据来源：钟楼百科 2026-10-01 抓取（25 个非旅行者角色页）与 2026-10-04 抓取（5 个旅行者角色页）；
> 逐页 SHA256 见 `references/wiki-index.json`，快照在 gitignored 的 `references/wiki/`。
> 引用格式：`百科《页名》· 抓取日期 · 区域`（`sources.md` §3）。
> 层级（`sources.md` §2）：**L1** = 角色页「规则细节」/《相克规则》；**L4** = 角色页「角色简介」「运作方式」。
> 无「规则细节」内容的角色只有 L4 参考可用；与 L1/L2 冲突时以 L1/L2 为准，并登记 `rulings.md`。
> 「能力类型」是角色页「角色信息」节的百科机制标签，用于规划实现，不等于内核触发类型（见 `architecture/current.md` §2.3）。
> 相克条目汇总见文末；回归测试素材见 `character-examples.md`。

## 镇民（13）

### 钟表匠 `clockmaker`
**能力类型**：获取信息、进场能力
**来源**：百科《钟表匠》· 2026-10-01 抓取 · 规则细节（L1）。

1. 当钟表匠即将被唤醒之前，说书人会根据当前场上的情况给出实时的信息。这意味着钟表匠得知的信息可能会与游戏初始时的情况有所不同，因为有一些角色的能力能够在游戏的过程中改变玩家的角色（如麻脸巫婆和理发师等）。
2. 钟表匠在获得信息时，说书人需要每次抽取两名玩家（其中一名为恶魔，另一名为爪牙，必须是两名不同的玩家）进行距离计算，直到将场上所有的“恶魔-爪牙”组合遍历完毕。这一过程类似于厨师，会进行多次判断，因此某些角色可能会在不同的玩家组合中被当作为不同的结果（如间谍、陌客、照看小怪宝的爪牙等）。最后，说书人会将这些距离值中的最小值作为信息提供给钟表匠。
3. 在计算距离时，距离值等同于：恶魔与爪牙这两名玩家之间的玩家数量+1。因此，钟表匠能得知的最小数字为“1”。（然而，在极端情况下，如果场上缺乏某种类型的角色，如无恶魔或无爪牙的时候，钟表匠会得知“0”。）
4. 在抽取两名玩家的组合时，即使是已死亡的玩家也依然会被钟表匠进行探查。
5. 相克规则：召唤师会被钟表匠当作恶魔。

### 筑梦师 `dreamer`
**能力类型**：获取信息
**来源**：百科《筑梦师》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

1. 筑梦师能得知一名玩家可能对应的角色，但不能确认哪个是正确的。
2. 每个夜晚，筑梦师需要选择一名其他玩家，并得知一个善良角色与一个邪恶角色，其中一个是那名玩家的真实角色。
3. 筑梦师得知的错误角色标记取决于所选玩家的真正的角色类型。如果筑梦师选择的玩家是镇民或外来者，对应的错误的邪恶角色可以是爪牙或恶魔。如果筑梦师选择的玩家是爪牙或恶魔，对应的错误的善良角色可以是镇民或外来者。
4. 筑梦师不能选择自己和旅行者作为目标。
5. 每个夜晚，唤醒筑梦师。让他指向除自己和旅行者外的任意一名玩家。如果被选择的玩家的真实角色是镇民或外来者，向筑梦师展示他的真实角色和任意一个爪牙或恶魔角色标记。如果被选择的玩家的真实角色是爪牙或恶魔，则给筑梦师展示他的真实角色和任意一个镇民或外来者角色标记。让筑梦师重新入睡。
6. 如果筑梦师选择了一名邪恶玩家，你能通过这种方式来帮助邪恶阵营：你可以给筑梦师展示邪恶玩家正在伪装的虚假角色，或者展示一些需要隐藏自己的角色，例如舞蛇人、贤者、畸形秀演员或呆瓜。

### 舞蛇人 `snake-charmer`
**能力类型**：角色变化、阵营转变、中毒、进场能力
**来源**：百科《舞蛇人》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 相克规则（与华灯系列角色）：梼杌——如果梼杌的角色发生了交换，因为梼杌失去能力的爪牙依然失去能力。

L4 · 角色简介 / 运作方式：
1. 舞蛇人会得知哪些玩家不是恶魔；但是如果舞蛇人太过于冒失或贪婪，自己就会成为恶魔。
2. 每个夜晚，舞蛇人需要选择一名存活玩家。如果那名玩家不是恶魔，无事发生。当选中一名恶魔时，舞蛇人变成那个恶魔并转为邪恶，那名恶魔则转为善良并永久中毒。
3. 如果具有舞蛇人能力的哲学家选中了恶魔玩家并变成了新的恶魔，原本的恶魔会变成中毒的哲学家。
4. 每个夜晚，唤醒舞蛇人。让他指向任意一名存活玩家。
5. 如果被选择的玩家不是恶魔，则无事发生。让舞蛇人重新入睡。
6. 如果被选择的玩家是恶魔，旧的舞蛇人变为新的（邪恶）恶魔，并且旧的恶魔变为新的（善良）舞蛇人。
7. 在魔典中交换舞蛇人和恶魔的角色标记。
8. 在新的舞蛇人角色标记旁放置“中毒”提示标记。
9. 唤醒新的恶魔并依次向他展示“你是”信息标记、向下的大拇指、“你是”信息标记、然后是恶魔的角色标记。（这代表该玩家现在是邪恶的恶魔。）让新恶魔重新入睡。
10. 唤醒新的舞蛇人并依次向他展示“你是”信息标记、向上的大拇指、“你是”信息标记、然后是舞蛇人的角色标记。（这代表该玩家现在是善良的舞蛇人。）让新舞蛇人重新入睡。
11. 在舞蛇人属于邪恶阵营，或者恶魔属于善良阵营的特殊情况下，依旧相应地交换他们的阵营。

### 数学家 `mathematician`
**能力类型**：获取信息、回溯型能力
**来源**：百科《数学家》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」「提示标记」「范例」（L4 补充）。

L1 · 规则细节（均为相克条目）：
1. 侍女：侍女会得知数学家是否醒来，即使她是在数学家之前醒来。
2. 疯子：数学家会得知疯子是否攻击了与真正的恶魔不同的目标。
3. 酒鬼：数学家会得知酒鬼产生了错误信息或“能力未正常生效”。
4. 提线木偶：数学家会得知提线木偶产生了错误信息或“能力未正常生效”。
5. 相克规则（与华灯系列角色）：悟道者——数学家会得知悟道者产生了错误信息或“能力未正常生效”。
6. 相克规则（与华灯系列角色）：引路人——引路人会得知数学家是否被影响，即使他是在数学家之前醒来。

L4 · 角色简介 / 运作方式：
1. 数学家会得知从黎明开始，有多少事情“出错了”。
2. 当一个角色的能力受到其他角色的影响而无法按预期方式发挥作用时，数学家会得知这些异常的发生。如果由于其他角色的影响使得一名玩家获得一条本应正确，实则错误的信息时，或者本应产生效果的角色能力没有生效时，数学家就会得知这些情况。
3. 数学家不会得知异常发生在哪名玩家身上，只会得知异常在多少名玩家身上发生了。
4. 数学家的能力不会检测数学家自身是否未正常生效。
5. 数学家不会检测中毒和醉酒这些状态本身，而是检测因为中毒和醉酒而导致的没有按照预期发挥作用的能力。
6. 每当一名玩家的角色能力由于其他角色的能力而未正常生效时，在该玩家的角色标记旁放置“未正常生效”提示标记。
7. 每个夜晚，唤醒数学家。对他用手势比划数字（0，1，2 等），这个数字等同于魔典中“未正常生效”提示标记的数量。让数学家重新入睡。
8. 移除所有“未正常生效”提示标记。

9. 提示标记「未正常生效」：每当有玩家的能力因为受到其他角色能力的影响而未正常生效时，在该玩家的角色标记旁放置。
10. 同一名玩家不论当天能力有多少次未正常生效，或换过角色后在不同角色下有多少次未正常生效，都最多只放 1 枚。
11. 移除时机：数学家获取信息后，说书人可自行方便移除；或在黎明时移除。
12. 只要剧本中有数学家，且数学家在该剧本中能够中途被创造出来，或能被其他角色获取到能力，则不论数学家是否在场，都应该及时记录各种未正常生效的情况，并在有数学家出现且在夜晚行动顺序轮到他时反馈给数学家。

### 卖花女孩 `flowergirl`
**能力类型**：获取信息、投票、回溯型能力
**来源**：百科《卖花女孩》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页「规则细节」内容为「无」）。

1. 卖花女孩会得知恶魔是否参与了投票。
2. 无论被提名的玩家是否被处决，恶魔的投票都会被卖花女孩计算在内。
3. 卖花女孩的能力不会检测到恶魔玩家因为其他的原因而举手表决。例如恶魔玩家举手“投票”选择晚餐吃什么，或者恶魔玩家举手赞成流放旅行者，都不会被卖花女孩的能力检测到。
4. 如果在原恶魔投票之后，卖花女孩得知该信息之前，恶魔玩家发生了改变，卖花女孩的能力还是会检测到原恶魔是否投票。
5. 如果有两名或更多的恶魔玩家在场，卖花女孩的能力都会检测他们当中是否有任一恶魔投票，即使那些死去的恶魔也能检测到。哪怕只有一名恶魔玩家投票，卖花女孩得知的信息都是“是”。
6. 每个黎明，在卖花女孩角色标记旁放置“恶魔未投票”提示标记，并移除“恶魔已投票”提示标记（如果有）。每个白天，如果恶魔在任何处决中投票，则将“恶魔未投票”提示标记替换为“恶魔已投票”提示标记。
7. 除首个夜晚以外的每个夜晚，唤醒卖花女孩。如果卖花女孩被标记为“恶魔未投票”，摇头告知否。如果卖花女孩被标记为“恶魔已投票”，点头告知是。让卖花女孩重新入睡。
8. 如果你忘记了恶魔是否在白天投票，在夜晚唤醒恶魔，并向他展示“你今天投票了吗？”信息标记。他必须诚实回答，然后重新入睡。

### 城镇公告员 `town-crier`
**能力类型**：获取信息、提名、回溯型能力
**来源**：百科《城镇公告员》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页「规则细节」内容为「无」）。

1. 城镇公告员得知爪牙是否提名。
2. 每个夜晚，城镇公告员都会得知“是”或“否”。
3. 他不会得知哪些玩家是爪牙或有多少爪牙进行了提名，只会得知今天白天是否有爪牙发起了提名。
4. 每个黎明，在城镇公告员角色标记旁放置“爪牙未提名”提示标记，并移除“爪牙已提名”提示标记（如果有）。每个白天，如果有任何爪牙发起提名，则将“爪牙未提名”提示标记替换为“爪牙已提名”提示标记。
5. 除了第一个夜晚的每个夜晚都唤醒城镇公告员。如果城镇公告员被标记为“爪牙未提名”，摇头告知否。如果城镇公告员被标记为“爪牙已提名”，点头告知是。让城镇公告员重新入睡。然后移除“爪牙已提名”标记，如果有的话。

### 神谕者 `oracle`
**能力类型**：获取信息
**来源**：百科《神谕者》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

1. 神谕者会得知有多少死亡玩家是邪恶的。
2. 由于神谕者每晚在恶魔之后行动，所以神谕者的信息以当晚黎明时的状态为基准，他得知的是在所有玩家都睁开眼睛时，死亡的邪恶玩家数量。
3. 神谕者能力能检测死去的爪牙和恶魔，以及任何属于邪恶阵营的玩家。例如邪恶的旅行者，或者变得邪恶的镇民或外来者。
4. 在计算死亡玩家的数量时，请记住计算在魔典中倒置的镇民和外来者角色标记，因为这意味着他们现在属于邪恶阵营。
5. 除了第一个夜晚的每个夜晚，唤醒神谕者。对他用手势比划已死亡的邪恶玩家的数量 (0，1，2等）。让神谕者重新入睡。

### 博学者 `savant`
**能力类型**：获取信息、拜访说书人
**来源**：百科《博学者》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 博学者在中文社区内的“谜题”式信息方式引起了设计师的兴趣，对于“是否应该给博学者提供谜题类信息”，设计师的回复如下（原文翻译）：“从规则上来讲，给出这样的信息是不允许的，因为这种含糊不清的内容并不能算是‘正确’或是‘错误’的信息。然而，如果说书人愿意以这样的方式给出信息，也没有任何问题。因为这允许了新人玩家在伪装自己是博学者时有更为宽松的要求——他们不需要编造明显正确或是错误的信息便能成功地伪装。说书人能够在一定限度内去‘犯一些错’，而这会使得玩家们也因此在伪装上更为容易。编造谜题也会让游戏变得更有趣。”
2. 如果你在作为说书人时想要给出谜题类的信息，那么你需要注意适时给出更为严肃的信息来“以假乱真”，或是适当协助邪恶玩家进行一些谜题的伪造，来帮助他们显得更像是真正从你这里获得了谜题类信息一样。

L4 · 角色简介 / 运作方式：
1. 博学者能得知惊人的信息，每一个白天，甚至每一局游戏里他能得到的信息都不会相同，但其中一半是错误的。
2. 每个白天，说书人选择两条信息提供给博学者。一条必须是正确的，一条必须是错误的，博学者不知道哪条对哪条错。
3. 是否与说书人交谈取决于博学者而非说书人。
4. 博学者从说书人处获取信息不是公开交流，因此其他玩家不能旁听。博学者会秘密地获取信息。
5. 博学者可以选择不从说书人那里获取信息，如果他愿意的话。
6. 醉酒或中毒的博学者可能会得到两条正确信息或两条错误信息。
7. 每个白天仅限一次，如果博学者要求与你进行私聊，请和他一起离开玩家围成的圆圈，保证你们的私聊不会被偷听。
8. 以耳语的方式告知博学者一真一假两条信息。

### 女裁缝 `seamstress`
**能力类型**：获取信息、限次能力
**来源**：百科《女裁缝》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

1. 女裁缝能得知两名玩家是否属于同一阵营。
2. 女裁缝每场游戏只能得到一次信息，所以女裁缝最好是选择最佳时机来使用能力，还要选择最关键的玩家。
3. 女裁缝可以选择除自己外的任何玩家，无论他是生是死，甚至可以选择旅行者。
4. 每个夜晚，唤醒女裁缝。她要么摇头不使用能力，要么指向另两名玩家。
5. 如果她摇头，无事发生。让女裁缝重新入睡。
6. 如果她指向两名玩家，要么点头代表是（表示这些玩家是同一阵营），要么摇头代表否（表示这些玩家不是同一阵营）。让女裁缝重新入睡。在女裁缝使用能力后，为她放置“失去能力”提示标记，并从夜晚顺序表上移除她的夜晚标记。

### 哲学家 `philosopher`
**能力类型**：获得能力、限次能力、持续检测型能力、醉酒
**来源**：百科《哲学家》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 与侍臣相似的是，如果哲学家所选择的角色的在场数量超过1人，那么哲学家的能力只会使得其中一名玩家醉酒。但通常来说，说书人应该倾向于优先让存活的玩家醉酒。
2. 相克规则：赏金猎人——如果哲学家获得了赏金猎人的能力，可能会有一名镇民玩家转变为邪恶。

L4 · 角色简介 / 运作方式：
1. 哲学家能够决定自己的能力是什么。
2. 他可以选择获得其他角色的能力，但每局仅限一次。当他这么做时，他获得那个角色的能力，但不会变成那个角色。
3. 他在选择获得谁的能力时可能会想要思考一小会儿。
4. 如果哲学家选择了一个已经在游戏中的角色，该角色对应的玩家醉酒。
5. 如果哲学家死亡，醉酒或中毒了，那么那名醉酒的玩家会再次恢复清醒。
6. 如果哲学家之前选择了不在场的角色，但之后被选择的角色在场了，被选择的角色对应的玩家也会醉酒。
7. 如果哲学家获得了一种在夜晚使用的能力，他将在该角色应该被唤醒的时候被唤醒。
8. 如果这个角色能力是“首个夜晚”能力，他会在当晚使用该能力。
9. 如果哲学家通过集骨者重新获得了他的能力，或由于咖啡师使用了两次他的能力，哲学家可以选择一个新的能力，或者和以前一样的能力。
10. 如果哲学家获取的能力在死亡时生效，例如呆瓜的能力，那么当哲学家死亡后，他选择的角色能力就会生效。
11. 每个夜晚，唤醒哲学家。他要么摇头不使用能力，要么指向角色列表上一个镇民或外来者图标。让哲学家重新入睡。
12. 如果他指向的是不在场的角色，将哲学家角色标记更换为他所选的角色标记，并放置“是哲学家”提示标记。
13. 如果他指向的是一个已在场的角色，该角色醉酒，在角色标记旁放置“醉酒”提示标记。
14. 如果哲学家死亡，醉酒的玩家将恢复清醒，此时需要移除“醉酒”提示标记。

### 艺术家 `artist`
**能力类型**：获取信息、拜访说书人、限次能力
**来源**：百科《艺术家》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 请注意说书人有权回答“我不知道”，且这样会使得艺术家的能力被浪费掉。针对含糊不清的问题，或者玩家尝试用多个问题嵌套成一个问题，或是如果说书人认为让玩家“重新再问一个问题”会导致对现在的问题有一定程度的暗示作用，那么这种时候，说书人都可以回答“我不知道”。

L4 · 角色简介 / 运作方式：
1. 艺术家可以向说书人提出任一是非问题。
2. 艺术家可以询问有关任何内容的问题，也可以随心所欲的遣词造句来提问。
3. 说书人需要诚实地回答“是”、“不是”，或“我不知道。”
4. 是否提问由艺术家决定，而非说书人。
5. 艺术家向说书人询问不是公开交流，因此其他玩家不能旁听。艺术家会秘密地询问并获取问题的答案。
6. 在任何一个白天，艺术家都可以要求与你进行私聊。请和他一同离开玩家围成的圆圈以保证你们的私聊不会被偷听。
7. 艺术家会问你一个问题。你需要以耳语的方式回答他“是”、“不是”或“我不知道”。
8. 如果你不能用这三种答案进行回答，让他重新问一个问题。
9. 艺术家在使用他的能力之后，为他放置“失去能力”提示标记。
10. 在艺术家拜访说书人并询问是非问题后，放置在艺术家角色标记旁。
11. 不论艺术家是否醉酒中毒，都要放置该标记。

### 杂耍艺人 `juggler`
**能力类型**：获取信息、进场能力、回溯型能力、公开触发能力
**来源**：百科《杂耍艺人》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 不建议杂耍艺人在进行猜测时，多次进行所选玩家与角色的猜测组合完全相同的猜测。（如猜测小明是数学家三次。）但杂耍艺人仍然可以猜测同一名玩家为不同的角色多次，或猜测多名玩家为同一角色多次。
2. 如果杂耍艺人的玩家是新人玩家，说书人可以对他进行宽容处理：在他忘记使用自己的能力的当晚唤醒他，并正常告知他信息。此时“0”为正确信息。然而如果是老手玩家，说书人则需要严格进行要求，那名玩家必须要公开声明自己是杂耍艺人之后，才能够在夜晚获得信息（即使他公开声明之后不进行任何猜测，也一样能够获得信息）。

L4 · 角色简介 / 运作方式：
1. 在第一个白天，杂耍艺人可以对任意玩家的角色进行猜测。当晚，他会得知他猜对的次数……如果他没有被杀害的话。
2. 他必须公开猜测，以使所有玩家听到他猜测的内容。他可以猜测零个角色，或者最多猜测五个角色，他所猜测的玩家和角色可以相同也可以不同。
3. 如果杂耍艺人在醉酒或中毒时做出了猜测，但当晚他的能力触发时却清醒且健康，那么说书人仍然会给他真实的信息。
4. 在第一个白天，如果杂耍艺人声明使用他的能力，你需要拿着魔典进入玩家围成的圆圈内。杂耍艺人最多可以做出五次猜测，每次猜测选择一名玩家和一个角色。对于每个正确的猜测，放置一枚“猜测正确”提示标记在杂耍艺人角色标记旁。（确保其他玩家不会看到你放置了几枚提示标记。）
5. 当晚，唤醒杂耍艺人。对他用手势比划等同于“猜测正确”提示标记的数量（0，1，2 等）。让杂耍艺人重新入睡。在稍后说书人方便的时候，移除所有“猜测正确”提示标记以及杂耍艺人的夜晚标记。

### 畸形秀演员 `mutant`
**能力类型**：疯狂、处决
**来源**：百科《畸形秀演员》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

1. 畸形秀演员如果试图揭露自己是谁，他就会被处决。
2. “疯狂”是一个术语，意思是“你正在尝试说服他人相信某件事情”。所以，“畸形秀演员‘疯狂’地证明自己是畸形秀演员”，这意味着他正在试图说服他人相信他是畸形秀演员。“他‘疯狂’地证明他是外来者”，这意味着他正在试图说服他人相信他是外来者。
3. 说服的形式包含口头暗示自己的角色，也包含在自己的角色被质疑时的保持沉默。
4. 畸形秀演员是否“疯狂”由说书人来决定。
5. 如果你认为他正在以任何方式证明自己是一名外来者，你就可以处决他，即使在提名阶段之外，甚至是在晚上都可以处决他。如果你这样做，正常情况下这意味今天白天不会再有其他人被处决，因为每个白天只有一次处决。
6. 如果畸形秀演员晚上暗示他是畸形秀演员，那么你在当晚可以处决他，即使今天白天已经有人被处决。宣布他的死亡，并正常进行夜晚。明天仍然可能发生一场处决。
7. 在游戏里的任何时间点（包括夜晚），如果你认为畸形秀演员“疯狂”地证明了他是一名外来者，那么你就可以决定处决畸形秀演员；向所有人宣布他被处决，并在魔典中为他放置帷幕标记。
8. 如果这次处决发生在白天的常规处决之前，则直接进入到夜晚阶段。（每个白天最多能进行一次处决。）

5. 如果呆瓜玩家没有意识到他必须在死亡时选择一名玩家，私下提醒他。新手玩家可能不明白他的角色如何运作。

### 镜像双子 `evil-twin`
**能力类型**：暴露角色、进场能力、获取信息、处决、特殊胜利失败条件

2. 由说书人来选择镜像双子与一名对立阵营玩家配对，被选择的玩家是对立双子。

6. 两个双子都存活时善良阵营无法获胜；此时即使恶魔死亡，游戏也会继续。善良阵营要杀死镜像双子以取得胜利。

9. 如果两个双子都是相同阵营，则由说书人为镜像双子重新选择一名玩家成为对立双子。
10. 初始设置时，在一名善良玩家的角色标记旁放置“对立双子”提示标记以表示他是与镜像双子阵营对立的双子。在首个夜晚，同时唤醒两名双子：指向邪恶双子，并对善良双子展示邪恶双子的角色标记；指向善良双子，并对邪恶双子展示善良双子的角色标记；让他们重新入睡。
11. 如果麻脸巫婆在最后一夜创造了一个镜像双子，说书人可以选择恶魔或一名死亡的玩家作为对立双子，这样的话，善良玩家仍然有机会获胜。
12. “对立双子”提示标记的放置时机：为首个夜晚做准备时；或当前对立双子与镜像双子同一阵营时；或有新的镜像双子被创造出来时。
13. “对立双子”提示标记的放置条件：当需要放置此提示标记时，选择与当前的镜像双子对立阵营的任意一名玩家，在其角色标记旁放置。
14. “对立双子”提示标记的移除时机：镜像双子死亡或离场时。

### 女巫 `witch`
**能力类型**：额外死亡、提名、持续检测型能力
**来源**：百科《女巫》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

2. 女巫的诅咒只持续一个白天，但女巫可以每晚一次又一次地诅咒同一名玩家。
3. 只剩三名玩家存活时，女巫的诅咒立即解除，女巫也无法再进行夜晚行动。
4. 每个夜晚，唤醒女巫。让她指向一名玩家。让女巫重新入睡。在被选择的玩家角色标记旁放置“被诅咒”提示标记。下个白天，如果被标记为“被诅咒”的玩家发起了提名，立即宣布他死亡。（提名正常进行）

### 洗脑师 `cerenovus`
**能力类型**：疯狂、处决、暴露角色
**来源**：百科《洗脑师》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 相克规则：哥布林——洗脑师可以选择将玩家洗脑成哥布林。

L4 · 角色简介 / 运作方式：
1. 洗脑师促使玩家假装成与自己实际角色不同的角色。
2. 洗脑师会选择让一名玩家“疯狂”地证明自己是某个镇民或外来者角色。
3. 被选择的玩家明天必须试图说服其他玩家相信他是这个角色，否则就会死亡。
4. 简短的暗示不足以避免死亡；玩家必须付出努力说服其他玩家。
5. 虽然疯狂的玩家不会被强迫一定要说出他不想说的东西，但是如果说书人感受不到他的努力，他就会付出代价。
6. 疯狂的邪恶玩家可能会以这种方式被处决，但“可能”意味着说书人可以选择不这么做，以防止邪恶玩家通过这种策略获胜。
7. 像畸形秀演员一样，执行处决惩罚计入每天的处决限制。
8. 每个夜晚，唤醒洗脑师；让洗脑师指向一名玩家和角色列表上一个镇民或外来者图标；让洗脑师重新入睡。
9. 为这名玩家放置“疯狂”提示标记并唤醒这名玩家，依次向他展示“该角色的能力对你生效”信息标记、洗脑师的角色标记、他要疯狂证明的角色标记；让那名玩家重新入睡。
10. 在下一个白天或夜晚，如果被选择的玩家没有尽最大努力去说服其他玩家他是被选择的角色，说书人就可以处决他；向所有玩家宣布他的死亡。
11. 如果说书人在白天的常规处决前处决了他，则直接进入夜晚阶段（每个白天最多一次处决）。
12. “疯狂”提示标记的放置时机：在洗脑师夜晚行动并选择了玩家和善良角色后。
13. “疯狂”提示标记的放置条件：在洗脑师要洗脑的玩家，其角色标记旁放置；若此时洗脑师醉酒中毒，不放置该标记。
14. “疯狂”提示标记的移除时机：在下一个夜晚的黎明时，或洗脑师死亡或离场时。
15. 在实体游戏中，因为只有一个“疯狂”标记，因此需要说书人在洗脑师第二夜行动后，转移疯狂标记，但需要注意此时到黎明之前，上一夜洗脑师选择的玩家仍然还处于疯狂状态，并且可能会因为不够疯狂而被处决。

### 麻脸巫婆 `pit-hag`
**能力类型**：角色变化、免死、额外死亡
**来源**：百科《麻脸巫婆》· 2026-10-01 抓取 · 规则细节（L1）。

L1 · 规则细节：
1. 说书人应该如何处理“因为麻脸巫婆创造了恶魔”而导致的死亡：
   - 麻脸巫婆造成死亡的时间范围为当前剧本中首个能够造成死亡的恶魔行动开始前，到最后一个能够造成死亡的恶魔行动结束后。
   - 在这个期间，说书人能够自由决定是否让某名玩家死亡，或让被恶魔攻击的某名玩家存活。
   - 说书人在这个时间范围内，可以分别在不同的恶魔行动前或后多次执行造成或阻止死亡的效果。
   - 一旦说书人决定杀死某个还未唤醒的恶魔，这名恶魔玩家当晚就不会被唤醒。否则，就需要唤醒这名玩家。这对于在创造出哈迪寂亚等带有特殊效果的恶魔时非常重要。
   - 说书人只能造成更多的死亡或阻止原本要发生的死亡，其他类型的恶魔能力无法阻止，如普卡的中毒、哈迪寂亚的复活等。
   - 不建议说书人阻止恶魔成功攻击的玩家的死亡，并再自己决定让这名玩家死亡，因为这会造成更多的混乱。恶魔攻击后无法杀死某名玩家再由说书人决定杀死，这种情况不算在内。
   - 说书人造成的死亡视为麻脸巫婆造成，因此不会触发贤者、唱诗男孩等角色的能力，也能够成功杀死士兵（如果麻脸巫婆没有照看小怪宝的话）。
   - 只要麻脸巫婆创造了恶魔，即使在那之后麻脸巫婆离场、失去能力或死亡，当晚说书人仍然可以决定造成或阻止死亡。
   - 说书人只能阻止恶魔造成的死亡，由非恶魔玩家造成的死亡无法阻止。
2. 相克规则：村夫——如果村夫在场数量不足3人，麻脸巫婆可以创造新的村夫。如果她这么做，村夫的醉酒效果可能会更换目标。
3. 相克规则：异端分子——互为克星的角色在同一时间里只能有其中一个角色在场。
4. 相克规则：落难少女——如果麻脸巫婆创造了落难少女，改为由说书人来决定哪一名玩家变成落难少女。
5. 相克规则：异教领袖/政客/莽夫/食人魔——被麻脸巫婆创造的邪恶异教领袖/政客/莽夫/食人魔无法因为自身能力转变为善良阵营。
6. 相克规则：召唤师——如果召唤师创造了第二个存活的恶魔，当晚的死亡由说书人决定。
7. 相克规则：利维坦——利维坦不能在第五天之后加入游戏。
8. 相克规则（与华灯系列角色）：戏子——互为克星的角色在同一时间里只能有其中一个角色在场。
9. 相克规则（与华灯系列角色）：梼杌——如果梼杌变成了其他角色，因为梼杌而失去能力的爪牙会立即死亡。
10. 相克规则（与华灯系列角色）：戏子（改）——麻脸巫婆无法创造戏子（改），麻脸巫婆创造的邪恶玩家无法获得戏子（改）的能力。

## 恶魔（4）

### 方古 `fang-gu`
**能力类型**：角色变化、阵营转变、限次能力、设置调整
**来源**：百科《方古》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 相克规则：红唇女郎——如果即将出现两名存活的恶魔，其中之一是由红唇女郎转变的，红唇女郎不会变成恶魔。

L4 · 角色简介 / 运作方式：
1. 方古会侵染外来者。
2. 方古首次攻击并成功杀死外来者时，改为方古死亡，外来者变成邪恶的方古。
3. 这种情况在整局游戏仅能出现一次；如果新的方古攻击外来者，外来者正常死亡。
4. 新的方古也是恶魔，如果他死亡，善良阵营获胜；但他不会得知哪些玩家是爪牙。
5. 方古会使得在初始设置时增加一名外来者。
6. 如果方古攻击外来者，但外来者没有因此死亡，则外来者不会成为邪恶的方古，方古也不会死。
7. 在初始设置时，将角色标记放入盲抽袋前，把一个镇民角色标记替换为一个外来者角色标记。
8. 除首个夜晚外的每个夜晚，唤醒方古；让他指向一名玩家；让方古重新入睡。
9. 如果被选择的玩家不是外来者，为那名玩家放置“死亡”提示标记。
10. 如果被选择的玩家是外来者，且“限一次”提示标记已经被放置在魔典中，也为那名玩家放置“死亡”标记。
11. 如果被选择的玩家是外来者，且“限一次”提示标记不在魔典中，在原来的方古旁放置“死亡”提示标记。
12. 唤醒被选择的外来者，依次向他展示“你是”信息标记、向下的大拇指、方古角色标记。
13. 用多出的方古标记替换他的角色标记，且他转为邪恶阵营；让新方古重新入睡。
14. 把“限一次”标记放在魔典中心；与“每局游戏限一次”能力不同，这个标记在接下来的游戏中始终留在那里，即使方古死亡或改变角色。
15. “死亡”提示标记的放置时机：在方古夜晚行动并选择了玩家后放置。
16. “死亡”提示标记的放置条件：方古选择的玩家当前存活，且能被方古杀死，且方古未醉酒中毒，那么在该玩家的角色标记旁放置，用以提醒说书人在黎明时分宣布当晚的死亡玩家。
17. “死亡”提示标记的移除时机：在黎明时宣布死亡玩家后，说书人可以任由自己方便来进行移除。
18. “限一次”提示标记的放置时机：在方古即将成功杀死一名外来者，但此时魔典中央还未放置“限一次”提示标记时。
19. “限一次”提示标记的放置条件：在方古成功触发能力转化外来者时，放置在魔典中央。
20. “限一次”提示标记的移除时机：持续至整局游戏结束。

### 亡骨魔 `vigormortis`
**能力类型**：死后能力保留、中毒、邻近、持续检测型能力、设置调整
**来源**：百科《亡骨魔》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 相克规则：主谋——如果亡骨魔死亡，被亡骨魔杀死的主谋依然保留能力。

L4 · 角色简介 / 运作方式：
1. 亡骨魔每当杀死自己的爪牙时，会使爪牙保留能力。
2. 每当亡骨魔杀死一名爪牙时，虽然爪牙会死亡，但只要亡骨魔还存活，该爪牙就能保留能力，且仍能在夜晚行动。
3. 类似于诺-达鲺，那个被亡骨魔杀死的爪牙顺时针或逆时针方向最近的镇民玩家会中毒，即使该镇民已经死亡。
4. 如果亡骨魔死亡或失去能力，受亡骨魔影响的中毒玩家恢复健康。
5. 亡骨魔在杀死爪牙时总是会使一名镇民玩家中毒，在说书人选择中毒玩家时会跳过与爪牙相邻的非镇民角色。
6. 由说书人选择该爪牙哪一侧的镇民中毒。
7. 不仅是最后一个被亡骨魔杀死的爪牙，所有被亡骨魔杀死的爪牙都会保留能力并使一名镇民中毒。
8. 如果死亡的爪牙变成非爪牙角色，便不再使相应的镇民中毒，且不再保留能力。
9. 如果死亡的爪牙醉酒或中毒，也会失去能力直到再次恢复清醒和健康。
10. 在初始设置时，将角色标记放入盲抽袋前，把一个外来者角色标记替换为一个镇民角色标记（如果没有可以移除的外来者标记，则不需要添加镇民标记）。
11. 除首个夜晚外的每个夜晚，唤醒亡骨魔；让亡骨魔指向一名玩家；让亡骨魔重新入睡。
12. 如果被选择的玩家不是爪牙，为那名玩家放置“死亡”提示标记。
13. 如果被选择的玩家是爪牙，为那名玩家放置“死亡”和“保留能力”提示标记。
14. 距离爪牙顺时针或逆时针最近的镇民玩家中毒，为该镇民玩家放置“中毒”提示标记（顺时针和逆时针分别判断最近的一个镇民，并取这两个镇民的其中之一）。
15. “死亡”提示标记的放置时机：在亡骨魔夜晚行动并选择了玩家后放置。
16. “死亡”提示标记的放置条件：亡骨魔选择的玩家当前存活，且能被亡骨魔杀死，且亡骨魔未醉酒中毒，那么在该玩家的角色标记旁放置，用以提醒说书人在黎明时分宣布当晚的死亡玩家。
17. “死亡”提示标记的移除时机：在黎明时宣布死亡玩家后，说书人可以任由自己方便来进行移除。
18. “保留能力”提示标记的放置时机：在亡骨魔夜晚行动并选择了玩家后放置。
19. “保留能力”提示标记的放置条件：被亡骨魔成功杀死的玩家角色如果是爪牙角色，则在该玩家角色标记旁放置“保留能力”标记。
20. “保留能力”提示标记的移除时机：亡骨魔死亡或离场，或被标记的玩家角色不再是爪牙角色时移除。
21. “中毒”提示标记的放置时机：与“保留能力”标记一同放置。
22. “中毒”提示标记的放置条件：放置在与此次放置了“保留能力”标记的爪牙玩家邻近的镇民玩家之一的角色标记旁。
23. “中毒”提示标记的特殊说明：动态检测会检查标记有“保留能力”的玩家角色类型是否为爪牙，及与其邻近的镇民玩家是哪一玩家；一旦标记了此“中毒”标记的玩家不再是放置了“保留能力”标记的邻近的镇民玩家之一，就需要移动“中毒”标记至与“保留能力”的爪牙玩家同一侧的满足条件的玩家角色标记旁（不会因此将“中毒”标记替换到爪牙玩家的另一侧去）。
24. “中毒”提示标记的移除时机：亡骨魔死亡或离场，或与该中毒标记相对应的被标记了“保留能力”的玩家角色不再是爪牙角色时移除。

### 诺-达鲺 `no-dashii`
**能力类型**：中毒、邻近、持续检测型能力、进场能力
**来源**：百科《诺-达鲺》· 2026-10-01 抓取 · 角色简介 / 运作方式（L4；该页无「规则细节」小节）。

1. 在诺-达鲺顺时针和逆时针方向上最近的镇民中毒，无论这些镇民是存活还是死亡。
2. 如果诺-达鲺死亡或者因为其他原因失去能力，那么这两名镇民玩家恢复健康。
3. 总是会有两名镇民玩家因此中毒，诺-达鲺的效果会跳过与他相邻的非镇民角色。
4. 如果有玩家成为新的诺-达鲺，或一个中毒的镇民变成了一个非镇民角色，都会根据新位置关系立刻改变中毒的玩家。
5. 在为首个夜晚进行准备时，让两名与诺-达鲺邻近的镇民玩家中毒——在他们角色标记旁放置“中毒”提示标记。
6. 如果一名被诺-达鲺影响的镇民变成了一个非镇民角色，或者诺-达鲺变成了另一个角色，或者如果一个新的玩家变成了诺-达鲺，都会让与诺-达鲺现在邻近的镇民中毒，而之前邻近但现在不邻近的镇民恢复健康。如有需要，立即移除诺-达鲺的“中毒”提示标记。
7. 除首个夜晚外的每个夜晚，唤醒诺-达鲺。让诺-达鲺指向一名玩家。该玩家死亡，在他角色标记旁放置“死亡”提示标记。
8. 诺-达鲺的毒会跳过爪牙、外来者和旅行者。

### 涡流 `vortox`
**能力类型**：能力效果干扰、处决、特殊胜利失败条件
**来源**：百科《涡流》· 2026-10-01 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」（L4 补充）。

L1 · 规则细节：
1. 相克规则：报丧女妖——如果涡流杀死了报丧女妖，玩家仍然会得知正确信息。（中文百科上的‘通用简化原则’已涵盖包括多角色互动下的涡流信息的简化处理方式，此条仅作说明。）

L4 · 角色简介 / 运作方式：
1. 涡流使所有信息变得错误。
2. 任何时候角色是镇民的玩家通过能力获取信息时，他们会得知错误信息。
3. 哪怕他们醉酒或中毒，信息也一定是错误的。
4. 涡流不会影响其他人通过其他方式获得的信息，例如说书人解释的规则或玩家的角色或阵营的变化。
5. 当夜晚降临时，如果今天白天没有人被处决，邪恶阵营胜利；流放旅行者不算在内。
6. 只要涡流存活，每当有镇民因为能力需要说书人提供信息，说书人就必须提供错误信息。
7. 除首个夜晚外的每个夜晚，唤醒涡流；让涡流指向一名玩家，将该玩家杀死；该玩家死亡，在他角色标记旁放置“死亡”提示标记；让涡流重新入睡。
8. 每个黄昏，如果今天白天没有玩家被处决，游戏结束，邪恶阵营获胜。
9. “死亡”提示标记的放置时机：在涡流夜晚行动并选择了玩家后放置。
10. “死亡”提示标记的放置条件：涡流选择的玩家当前存活，且能被涡流杀死，且涡流未醉酒中毒，那么在该玩家角色标记旁放置，用以提醒说书人在黎明时分宣布当晚的死亡玩家。
11. “死亡”提示标记的移除时机：在黎明时宣布死亡玩家后，说书人可以任由自己方便来进行移除。

## 《相克规则》中涉及 S&V 角色的条目

> 来源：百科《相克规则》· 2026-10-01 抓取 · 相克规则列表（筛选口径：正文含 25 个 S&V 角色名的条目，共 39 条）。
> **首版只实现双角色相克**（`rulings.md` R-0002）：三角色及以上一律返回「未登记」，交说书人现场裁定。
> 这 39 条中**没有**两条都出自 S&V 25 角色的组合——对方角色均来自其他剧本、实验性角色或「华灯初上」系列社区剧本。
> 因此纯 S&V 对局中不会触发相克判定；相克解析器的首个真实用例要等跨剧本/旅行者角色加入。

### 通用说明（适用于所有相克判定）

1. 相克规则是规则而非灯神的能力，灯神的能力只是允许说书人来宣布这些规则。所有因相克规则而导致自己能力未正常生效的，不会计入到数学家的能力检测中。（如红唇女郎因为方古的相克规则，本该转变为方古但未转变成功，不会被数学家得知。）
2. 对于所有能够“获得能力”的角色，如果玩家即将获得某一角色的能力但该角色与另一在场角色满足“互为克星的角色在同一时间里只能有其中一个角色在场”的相克规则，则说书人需要提醒该玩家，他因为相克规则而无法获取对应角色的能力且告知相应的原因（如哲学家，此时需要为他展示相克规则的那个在场角色，且哲学家的能力会被视作已经使用）；或如果获取能力的操作为说书人选择，则说书人在规则允许的情况下为该玩家选择另一项可用能力（如炼金术士）。
3. 诸如麻脸巫婆将某名邪恶玩家变成哲学家后该哲学家选择获得异端分子之类的“三角色相克”问题，目前 Steven 的回复是：“三角色问题会比双角色问题更加复杂，需要考虑的东西更多”因此在短期内（话先不说死）不会整理“三角色相克”规则。但说书人依然可以类比双角色相克规则来进行处理，比如上述问题的处理方式可以参考：“允许麻脸巫婆将邪恶玩家变成哲学家，但不允许‘一名邪恶的哲学家’获得异端分子的能力”。

### 逐条组合

1. 异端分子与麻脸巫婆：互为克星的角色在同一时间里只能有其中一个角色在场。
2. 利维坦与麻脸巫婆：利维坦不能在第五天之后加入游戏。
3. 利维坦与贤者：每个夜晚*，利维坦要选择一名存活的善良玩家（与之前的每个夜晚不同）：如果贤者被选择，他的能力生效但不会死亡。
4. 主谋与亡骨魔：如果亡骨魔死亡，被亡骨魔杀死的主谋依然保留能力。
5. 数学家与疯子：数学家会得知疯子是否攻击了与真正的恶魔不同的目标。
6. 数学家与酒鬼：数学家会得知酒鬼产生了错误信息或“能力未正常生效”。
7. 数学家与提线木偶：数学家会得知提线木偶产生了错误信息或“能力未正常生效”。
8. 瘟疫医生与镜像双子：如果说书人本应获得镜像双子的能力，改为一名玩家会变成镜像双子。
9. 陌客与贤者：陌客可能会被贤者当作杀死他的恶魔。
10. 暴乱与贤者：每个夜晚*，暴乱要选择一名存活的善良玩家（与之前的每个夜晚不同）：如果贤者被选择，他的能力生效但不会死亡。
11. 红唇女郎与方古：如果即将出现两名存活的恶魔，其中之一是由红唇女郎转变的，红唇女郎不会变成恶魔。
12. 召唤师与钟表匠：召唤师会被钟表匠当作恶魔。
13. 召唤师与麻脸巫婆：如果召唤师创造了第二个存活的恶魔，当晚的死亡由说书人决定。
14. 涡流与报丧女妖：如果涡流杀死了报丧女妖，玩家仍然会得知正确信息。（中文百科上的“通用简化原则”已涵盖包括多角色互动下的涡流信息的简化处理方式，此条仅作说明。）
15. 侍女与数学家：侍女会得知数学家是否醒来，即使她是在数学家之前醒来。
16. 哲学家与赏金猎人：如果哲学家获得了赏金猎人的能力，可能会有一名镇民玩家转变为邪恶。
17. 食人族与杂耍艺人：如果杂耍艺人在自己的首个白天猜测后在当天死于处决，当晚食人族会替杂耍艺人得知对应的信息。
18. 麻脸巫婆与落难少女：如果麻脸巫婆创造了落难少女，改为由说书人来决定哪一名玩家变成落难少女。
19. 麻脸巫婆与政客：被麻脸巫婆创造的邪恶政客无法因为自身能力转变为善良阵营。
20. 麻脸巫婆与异教领袖：被麻脸巫婆创造的邪恶异教领袖无法因为自身能力转变为善良阵营。
21. 麻脸巫婆与莽夫：被麻脸巫婆创造的邪恶莽夫无法因为自身能力转变为善良阵营。
22. 麻脸巫婆与食人魔：被麻脸巫婆创造的邪恶食人魔无法因为自身能力转变为善良阵营。
23. 麻脸巫婆与村夫：如果村夫在场数量不足 3 人，麻脸巫婆可以创造新的村夫。如果她这么做，村夫的醉酒效果可能会更换目标。
24. 洗脑师与哥布林：洗脑师可以选择将玩家洗脑成哥布林。
25. 理发师与异教领袖/莽夫/政客/食人魔：参考麻脸巫婆。建议“恶魔无法将一名邪恶玩家与异教领袖/莽夫/政客/食人魔交换角色，理发师的能力会因此被浪费”。
26. 理发师与落难少女：参考麻脸巫婆。建议“如果恶魔选择交换落难少女的角色，参与角色交换的另一名玩家改为由说书人来决定”。
27. 食人族与月之子/呆瓜：参考食人族与管家。建议“如果食人族获得了月之子/呆瓜的能力，他会得知这一信息”。
28. 戏子与镜像双子：互为克星的角色在同一时间里只能有其中一个角色在场。
29. 戏子与麻脸巫婆：互为克星的角色在同一时间里只能有其中一个角色在场。
30. 引路人与数学家：引路人会得知数学家是否被影响，即使他是在数学家之前醒来。
31. 悟道者与数学家：数学家会得知悟道者产生了错误信息或“能力未正常生效”。
32. 梼杌与镜像双子：镜像双子在梼杌的能力判断中被当作“不具有能力”。
33. 梼杌与麻脸巫婆：如果梼杌变成了其他角色，因为梼杌而失去能力的爪牙会立即死亡。
34. 梼杌与舞蛇人：如果梼杌的角色发生了交换，因为梼杌失去能力的爪牙依然失去能力。
35. 梼杌与理发师：如果梼杌的角色发生了交换，因为梼杌失去能力的爪牙依然失去能力。
36. 姑获鸟与镜像双子：如果姑获鸟获得了镜像双子的能力，新对立双子会知道“姑获鸟在场”，但不会知道姑获鸟是谁。

## 旅行者（5）

相克面：2026-10-04 快照的《相克规则》中 5 名旅行者 **0 命中**，不新增相克组合（R-0002 第 4 条）；
流放流程本身的口径（三分流 / 阈值 / 公开面）见 `rulings.md` R-0044，死亡后果见 R-0045，
与处决路径的接缝（处决不杀旅行者）见 R-0049。

### 怪咖 `deviant`
**能力类型**：免死
**来源**：百科《怪咖》· 2026-10-04 抓取 · 角色简介 / 运作方式 / 范例（L4；该页无「规则细节」小节）。

1. 角色能力：「如果你表现得很有趣，当天你不能被流放。」
2. 「有趣」由**说书人判定**（主观裁定点）：怪咖可以用任何方式逗乐（笑话 / 有趣的故事 / 神回复），
   说书人也可以与玩家协商把标准换成「传递正能量」「对他人有帮助」这类更宽松的替代。
3. 即使流放票数足够，说书人判定「有趣」时怪咖**依旧存活**；保护期间不死亡、也不触发死亡触发能力
   （《免死》，R-0045 第 3 条）。
4. 保护只覆盖「当天」：第二天不再有趣时，被流放即死亡（范例：第三个白天被保护、第四个白天死亡）。
5. 保护范围只作用于**流放致死**；平台的收口口径（达线时裁定、受保护不产生死亡、能力失效不进入裁定）
   见 `rulings.md` R-0048。

### 集骨者 `bone-collector`
**能力类型**：限次能力、获得能力
**来源**：百科《集骨者》· 2026-10-04 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」「提示标记」（L4 补充）。

L1 · 规则细节：
1. 「**重获**」（regain）以「先失去」为前提：死亡时**仍保有**能力的玩家（受亡骨魔影响死亡的爪牙、
   「假死」的僵怖）不会被再次授予能力；已经用过的限次能力也不会因为「仍保有」而恢复。
2. 重获非强制能力（艺术家 / 博学者一类）时，说书人无需提示可否使用；重获**夜晚会行动**的能力时，
   说书人必须主动唤醒该玩家。

L4 · 角色简介 / 运作方式 / 提示标记：
1. 角色能力：「每局游戏限一次，在夜晚时*，你可以选择一名死亡的玩家：他重新获得能力直到下个黄昏。」
2. 被选玩家保持死亡状态，但重新获得其角色能力；「首个夜晚」「每局游戏限一次」类能力可在黄昏前再次使用，
   即使先前已经用过。
3. 被选玩家**不会得知**自己被选中（但他可能很快发现自己又被唤醒、能力又能用了）。
4. 集骨者死亡 → 重获的能力立即终止；集骨者**用后即失去自身能力**（「失去能力」标记）；
   下个黄昏移除「重获能力」标记。
5. 提示标记：「重获能力」（放置条件：集骨者未醉酒中毒；移除时机：黄昏 / 集骨者死亡或离场）、
   「失去能力」（只要作出选择就放置，不论是否醉酒中毒；移除时机：集骨者死亡或离场）。

### 咖啡师 `barista`
**能力类型**：能力效果干扰、获得能力、暴露角色
**来源**：百科《咖啡师》· 2026-10-04 抓取 · 规则细节（L1）；以及同页「角色简介」「运作方式」「提示标记」（L4 补充）。

L1 · 规则细节：
1. 效果 1 期间，目标原有的醉酒 / 中毒被「暂时移除」，新增的醉酒 / 中毒同样「暂时无法生效」；
   窗口结束时恢复。失效期间这些标记仍按各自结束条件判断，到期照常移除（R-0047 第 1–3 条）。
2. 效果 1 的「必定正确信息」覆盖醉酒 / 中毒与涡流的必假（R-0047 第 4 条；百科举例：酒鬼也会得到
   他所以为的那个镇民角色的正确信息）。

L4 · 角色简介 / 运作方式 / 提示标记：
1. 角色能力：「每个夜晚，直至下个黄昏，由说书人二选一：1）一名玩家解除并免受醉酒和中毒影响，
   且会得知正确信息；2）一名玩家的能力可以生效两次。该玩家会得知是哪个效果。」
2. 目标与效果都由**说书人选择**；咖啡师不会知道选了谁 / 哪个效果，但受影响玩家**会得知**是哪个效果。
3. 效果 2 仍在能力原本的时间点生效：夜晚能力就唤醒两次；已用过的「每局游戏限一次」可以再用，
   没用过的则可在下个黄昏前用两次。
4. 提示标记：「清醒且健康」「行动两次」以及辅助第二次行动的「？」标记；每夜在下一次触发前移除
   上一夜的标记。
5. 平台口径（D5 第二批 / `rulings.md` R-0047 与 R-0052）：目标集合 = 本局**全部在局席位**（「任意一名
   玩家」，含咖啡师自己；死亡席位照样可标记，但只在候选预览里如实标注）；目标 × 效果是**一条原子裁定**
   （说书人受众的裁定点，候选形如 `healthy:seat:3` / `twice:seat:3`）；结算落一条持续型**窗口**效果，
   并向目标告知「是哪一个效果」（咖啡师本人不知情）。效果 1 期间目标身上压制维度的效果**挂起**
   （标记照记、维度暂清、窗口结束按同一 `EffectId` 恢复），「必定正确信息」覆盖涡流；效果 2 让夜晚槽位
   **重进一次**（请求标识带遍次），「每局限一次」的能力以总使用次数 &lt; 2 为上限（含女裁缝 / 艺术家 /
   呆瓜的死亡选择），已被计划判成「本夜无行动」的格由窗口重开；窗口在**下个黄昏**（下一个夜晚阶段开始）
   收口。哲学家「获得能力」的二次获得未定稿（R-0053 Open）——显式不重开、不静默产生第二条授予。

### 流莺 `harlot`
**能力类型**：获取信息、额外死亡、暴露角色
**来源**：百科《流莺》· 2026-10-04 抓取 · 角色简介 / 运作方式 / 范例（L4；该页无「规则细节」小节）。

1. 角色能力：「每个夜晚*，你要选择一名存活的玩家：如果他同意，你会得知他的角色，但是你们两个可能同时死亡。」
2. 目标自己做决定（点头同意 / 摇头拒绝）；同意 → 流莺得知其**角色**，**不含阵营**；拒绝 → 无事发生。
3. 说书人可以裁定两人**当夜同时死亡**（「死亡」标记，黎明时宣布）；选择应尽量「最有趣、最平衡」——
   例如恶魔揭露自己时不应直接杀死以结束游戏。
4. 流莺在白天可以讨论 / 声称自己今晚会选谁，但夜晚醒来后可以改选（实际选择以夜晚为准）。
5. 行动时点是**其他夜晚 · 黄昏**（首个夜晚不行动，见 D5 的黄昏清单）。
6. 平台口径（D5 首批 / `rulings.md` R-0051）：目标集合 = 全部**存活**席位（含流莺自己；来源没有排除条款）；
   同意 / 拒绝由说书人按线下流程收集后录入**一条裁定点**（拒绝 / 同意 / 同意且同死），信息只到流莺本人；
   能力未生效时展示照常、内容由说书人选角色标记（可能为假），且不产生同死；同死是真实夜死、按 R-0022
   到黎明才公告。信息不受涡流约束（R-0028 只作用于镇民玩家）。

### 屠夫 `butcher`
**能力类型**：提名、处决、额外死亡
**来源**：百科《屠夫》· 2026-10-04 抓取 · 角色简介 / 运作方式 / 范例（L4；该页无「规则细节」小节）。

1. 角色能力：「每个白天，首次处决后，你可以再次发起提名。」
2. 触发条件：当天**已经发生过处决**（被处决者即使没有死亡也算）；当天没有任何处决则不能用。
3. 额外提名可以提名当天**已经被提名过**的玩家，且**不占**屠夫当日的提名次数；仍需正常票数
   （达到存活玩家的一半），但**不需要超过**前一次被处决者的票数。
4. 每个白天最多一次：第二次处决之后不能再发起第三次提名。
5. 流放**不是处决**（范例：集骨者 / 流莺被流放的同一天没有处决 → 屠夫不能用；R-0044 第 1 条）。
6. 平台口径（D4 / R-0050）：当天首次处决后打开「额外提名窗口」——屠夫在局、存活且能力生效才开；
   开窗后白天保持 Open，只有屠夫本人能发起一次额外提名；第二次 `CloseDay` 执行后直接关账、不再开窗。
   流放不算处决；处罚处决是「非常规处决」，按《处决》「不影响游戏流程」不触发窗口（R-0020 不变）。
