## 要解决的问题

首版只覆盖《梦殒春宵》。胜负层明确排除了跨剧本的特殊条件：

- **角色**：主谋 / 圣徒 / 僵怖 / 小怪宝等不在 `SectsAndVioletsRoster`，契约闸一律显式拒绝；
- **剧本口径**：多恶魔 / 善良恶魔——R-0024 第 4 条的「没有任何恶魔角色 → 不判」只处理了
  配置异常，多恶魔与善良恶魔下的胜负读法要按百科重新核对；
- **最高层级**：「照看小怪宝的最后一名恶魔死亡」在 R-0024 第 3 条已登记「不在首版剧本，不实现」。

本票是**未来架构**票：把范围、依赖与开工前必须回答的问题登记为真；开工时按百科逐条核对来源。
