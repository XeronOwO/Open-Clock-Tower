# 账号与玩家名：让局内每个人知道对面是谁

- Status: In progress
- Priority: Medium
- Depends on: 无（M1 局内玩家名 + M2 账号系统本版一起做，口径见 D-0021）
- 落地方案：`docs/decisions/active.md` D-0021 / `docs/architecture/current.md` §4.1、§5

## 要解决的问题

现在平台只有**席位号**：玩家端与说书人端一律以 `1..N 号` 称呼玩家。玩家 aaa 坐在 1 号位时，
同桌的其他人（以及说书人）在界面上**看不到「1 号是 aaa」**——只有线下或语音里口头对号，
才能把席位号翻译成人名。后果：

1. 远程 / 网局时，「轮到 3 号做选择」「2 号被提名」「谁在卡着」都无法与具体的人对上；
2. 说书人找人与玩家互相沟通，都要额外维护一份口头映射；
3. 复盘 / 公告 / 提名记录的文案只能写「3 号」，每个人读的时候都要在心里翻译一遍；
4. 没有跨局身份：换一局就是新票据，名字与关系都不累积。

**现状清点**（代码即证据）：

| 位置 | 现状 |
|---|---|
| `src/OpenClockTower.Application/SeatTicket.cs` | 只有 `Seat` + `Ticket`，无账号 |
| `src/OpenClockTower.Application/GameSetup.cs` | 只有席位票据列表 + `StorytellerTicket`，无玩家名 |
| `src/OpenClockTower.Server/GameDbContext.cs` | 只有 Events / Snapshots / Receipts / Games 四张表，**没有账号表、没有席位绑定表** |
| `GameHub.JoinSeat(ticket, lastSequence)` | 只凭票据加入，没有账号入口 |
| `web/src/**` | 没有账号入口与玩家名呈现 |
| `docs/standard/terminology.md` | `account` / `account-name` / `display-name` / `seat-binding` / `account-session` 已登记（E30） |

## 范围（D-0021 定稿）

- **M1 局内玩家名**：席位显示账号的玩家名（`1 号 · aaa`），同桌所有人（含说书人）看到同一份映射；
  没有账号的游客席位一律回退 `N 号`。
- **M2 账号系统（本版一起做）**：注册 / 登录 / 跨局身份 / 玩家名来源与一次性恢复码找回；
  席位绑定属**会话信息**（不进事件流）；姓名不参与授权与任何规则判定。
- **M2 首版不做**：邮箱与第三方登录、管理后台、账号合并 / 删除、「我的对局」列表、多实例。

## 决定与依据（D-0021 定稿）

- **承载层级**：会话级。席位绑定与玩家名是**会话信息**（`SeatBindings` 表 + 会话读模型），
  不进事件流、不进 `GameState`；账号（`Users` 表）是全局身份。依据 D-0017 推论（席位名单来自
  会话信息）、D-0015（状态账只装游戏事实）与「姓名是会话事实」的判断；代价是复盘里的
  「谁」取**读取时**的玩家名，不提供逐步骤历史名。
- **来源与权限**：玩家名以账号为准——注册时设定、账号设置里随时可改、改名即时生效；
  不代设、不锁定（姓名不参与判定）。说书人 / 宿主保留**解除席位绑定**的兜底入口。
- **唯一性与冒用**：允许重名，服务端不做唯一性判定、不做阻塞——姓名是标签不是凭据；
  席位号始终与玩家名同屏。
- **M2 边界**：注册 / 登录 / 跨局身份 / 一次性恢复码；不做邮箱、第三方登录、管理后台、
  账号合并 / 删除与多实例。
- **术语**：`account` / `account-name` / `display-name` / `seat-binding` / `account-session`
  已登记（`docs/standard/terminology.md` §8），代码标识符与界面文案一律照此。
- 与 `replay-auto-review` 的关系：本票落地后，复盘文案的「谁」从席位号换成 `N 号 · 玩家名`，
  关闭该票残余事项 3；两票仍可独立回归。

## 落地清单（E30）

- 服务端：`Users` / `SeatBindings` 表、账号会话、`AccountHub`、`JoinSeat` 认领三路径、解除绑定；
- 投影：`SeatNames` 进玩家 / 说书人 / 复盘视图，`ReplayText` 统一「N 号 · 玩家名」口径；
- 前端：账号面板、加入流程、姓名呈现与缺失回退；
- 门禁与装置：凭据安全门禁扩展、`tools/verify-accounts.mjs`（第 14 个装置）、零信任 / 胜负装置扩展；
- 验收：批次 E30 逐行判定，票据移入 `done/`。
