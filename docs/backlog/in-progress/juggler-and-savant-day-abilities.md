# 白天信息族剩余两名：杂耍艺人 + 博学者

- Status: Todo
- Priority: Medium
- Depends on: 无（同族已落地：`done/retrospective-info-family.md`（回溯型读数口径 R-0037）、
  `done/seamstress-and-artist.md`（白天主动提问的裁定点形态 R-0040））

## 要解决的问题

首版 30 个角色里仍有两人没有契约，**带他们的局开不了白天**（`legality.day_contract_missing`，
`docs/architecture/current.md` §2.6「能力边界」；`done/day-phase.md` 的白天名单）：

- **杂耍艺人**：首个白天公开猜测、当晚得知猜对数量——白天入口与夜晚信息两头都缺；
- **博学者**：每个白天私下向说书人要「一真一假」两条信息——白天裁定点缺。

后果与已修的两个角色同族：不是"少一点信息"，是**这一局根本开不了**。

## 依据

- 百科《杂耍艺人》· 2026-10-01 抓取 · 角色能力——「在你的**首个白天**，你可以**公开**猜测任意玩家的
  角色**最多五次**。在**当晚**，你会得知猜测正确的角色数量。」；
  · 角色简介 2——必须公开（所有玩家听到）、可猜 0–5 个、玩家与角色可重复；
  · 角色简介 3——「如果在醉酒或中毒时做出了猜测，但当晚触发时却清醒且健康，说书人仍然会给他真实的信息」
  （= 生效判定在**触发时刻**，不在猜测时刻）；
  · 范例 2——「第四个夜晚，博学者变成了杂耍艺人。**下个白天**，新的杂耍艺人猜测……当晚得知『1』」
  （= 「首个白天」是**该角色**的第一个白天，不是整局的第一天；与《哲学家》提示 11 同义）。
- 百科《博学者》· 2026-10-01 抓取 · 角色能力——「每个白天，你可以**私下**询问说书人以得知两条信息：
  一个是正确的，一个是错误的。」；· 角色简介——说书人选两条、博学者不知道哪条对哪条、
  可以选择不要、醉酒 / 中毒时可能两条全对或全错。
- 同族读数口径：R-0037（读白天记录的能力按动作时刻快照）；R-0040（白天主动提问 = 玩家命令 → 归属裁定点）。

## 方案（机制清点后定稿）

**机制清点结论**（读源码得到的现状，与艺术家 / 女裁缝两族对照）：

| 要接的点 | 现状 | 缺口 |
|---|---|---|
| 开白天闸 | `GameCommandDispatcher.DispatchStartDay` 按 `DayActions.IsDayRelevant && !IsCovered` 拒绝 | 两名角色登记 `CoveredCharacters` |
| 白天玩家命令 | 已有形状：提名 / 投票 / 流放 / **艺术家的白天提问**（席位由凭据推导，命令面无自称身份） | 两条新命令 |
| 白天裁定点 | `ArtistQuestionMachine`：玩家命令 → `DecisionPointRaisedEvent`（归属席位）→ 说书人裁定 → `InformationResultIssuedEvent` 只到本人；挂起期间挡关账 / 处罚处决，强推则作废 | 同款两套（各自独立的状态与结案口径） |
| 杂耍艺人的夜晚格 | `NightOrderTable` 其他夜晚已有 `Action("juggler")`，契约目录里没有实现 | 新夜间契约（算猜对数） |
| 公开事实 | 白天公开面（`PlayerDay`）已有提名 / 投票 / 处决等；**没有**"玩家公开发言"这一类 | 新增一条公开事实 |
| 白天权限位 | `PlayerView.CanAskArtistQuestion` / `PendingQuestion` 已有先例 | 两人的权限位 |

**落地形状**：

- **博学者**（本轮先做）：白天命令（无参数）→ 裁定点（自由文本，两条用 `|` 分隔）→
  **两条** `InformationResultIssuedEvent` 只到本人；每个白天可问一次、可以不问（玩家不发起即不用）；
  说书人给的两条**一真一假由他自己掌握**，平台不判定哪条为真（D-0002），两条都标「可能为假」；
  能力未生效（醉酒 / 中毒 / 死亡）时由说书人自由给（可能两条都真或都假）；涡流在场时两条都必须为假
  （R-0028），失效分类并列进账。裁定值与格式不符 → **显式拒绝**（自由文本是用户输入，不抛异常）。
- **杂耍艺人**（随后做）：白天命令（0–5 条 `{席位, 角色}` 猜测）→ 公开事实（全体可见，必须公开）；
  夜晚格按**结算时刻**的角色快照算猜对数（平台计算，与数学家同族），信息只到本人；
  「首个白天」= **该角色**的第一个白天（角色变更后重新起算，与《哲学家》提示 11 同义）。

## 自检表（开工前逐条问过）

| 问题 | 结论 |
|---|---|
| 来源 | 百科《杂耍艺人》/《博学者》· 2026-10-01 抓取；同族读数口径 R-0037 / R-0040 |
| 规则 vs 平台选择 | 规则：猜 0–5 条 / 公开 / 当晚报数、「一真一假」、可不使用；选择：两条信息的**输入格式**（`|` 分隔）、
裁判点形状、公开事实怎么投影 → 登记 R-0057 |
| 状态属于谁 | 挂起中的提问属步骤机状态（与艺术家同族）；猜对数是**算出来的**，不落账 |
| 信息隔离 | 博学者的两条信息只到本人；杂耍艺人的**猜测**公开、**猜对数**只到本人——两条边界都要断言 |
| 确定性 | 无时间 / 随机 / IO；猜对数按结算时刻快照纯计算 |
| 家族对齐 | 与艺术家（白天主动提问）/ 数学家（平台算数字）两族逐条对照 |
| 结构门禁 | 新增事件必须被复盘目录认领；一文件一顶层类型 |
