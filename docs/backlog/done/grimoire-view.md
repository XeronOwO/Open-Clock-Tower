# 界面游戏化：魔典式小镇视图

- Status: Done
- Priority: Medium
- Depends on: `web/` 前端与说书人面板已落地（D-0018）；数据面 `StorytellerView`（席位 / 事实 / 效果 / 计划 / 卡点）已就位——本票是**呈现层改造**，不改规则内核

## 要解决的问题

需求方在 2026-10-02 提出（附官方魔典界面示例图）：当前说书人面板是**以数据与计算为中心**的表格看板
（状态账、效果归因链、两本账、最近变化），说书人要"逐行读"才知道谁是什么、谁怎么了；
而桌游的魔典是**以玩家（席位）为中心**的图形化牌桌——角色、生死、状态、提醒标记直接摆在桌上，
说书人一眼就能扫出局面。要求：把说书人端做得**更像一款游戏**。

术语：**魔典** `grimoire`（说书人手里的角色标记容器，说书人端界面沿用此词）、
**提示标记** `reminder-token`、**帷幕标记** `shroud`（死亡玩家角色标记上的标记）——
均见 `docs/standard/terminology.md`。

## 参考示例（需求方提供，不入库）

官方魔典（The Pandemonium Institute 的《梦殒春宵》线上版）的信息结构，逐块拆开看是：

- **小镇圆环**：11 名玩家按座位围成一圈，每人一张圆形**角色牌**（中央角色图标、牌下方角色名，
  牌圈按阵营着色）；牌下挂**玩家名条**（座位号 + 玩家名）。
- **存活 / 死亡**：存活者牌顶有一枚绿色小标签；死亡者牌上盖**黑纱帷幕**（`shroud`）。
- **计数与状态标记**：牌两侧有圆形数字标记（蓝 / 红，投票计数）；牌下有蜡烛 / 勾选一类小标记
  （行动 / 已投票等局内状态）。
- **提示标记**：圆环内侧漂浮紫色圆形小标记，就近挂在相关玩家旁——示例里是「哲学家」「公告员」
  「外来」，还有一条自定义文本「18 不共边」。
- **恶魔的伪装**：左下角独立托盘，放三张提供位角色（钟表匠 / 杂耍艺人 / 艺术家），可关闭。
- **局信息与菜单**：左上角剧本名 + 作者 + 人数构成（`7 民 1 外 2 爪 1 恶`）+ 一排标记计数；
  右上角菜单（角色能力表 [R] / 夜晚顺序表 [N] / 投票记录 [V] / 隐藏角色 [H] / 离开小镇）。
- 中心是剧本 logo，整体是暗色小镇场景（氛围演出）。

**素材合规**：示例图是官方美术，**不入库**（`AGENTS.md`：不提交官方美术资源）；
本票只借它的**信息结构与交互**，图形用自绘几何 / 文字 / emoji，或来源已登记的开源素材。

## 要做的事（说书人端）

1. **主视图 = 小镇圆环**（默认入口）：按席位围环渲染角色牌（角色名 + 阵营色 + 座位号 + 玩家名条），
   数据只来自 `StorytellerView`，前端不推断任何规则结论；
2. **生死可视化**：存活 / 死亡用牌面状态（帷幕标记 / 解除）；死亡时投票与状态标记同步更新；
3. **状态标记挂在牌上**：中毒 / 醉酒 / 阵营 / 角色变更 / 疯狂要求 / 效果链接（来源 + 挂起 / 终止）
   就近呈现，点开能看归因（谁、因何、何时、哪条效果）；
4. **提示标记**：把需要记的临时事实以 token 形式挂在席位旁（现有数据里 = 疯狂要求；
   自定义文本备注要不要做，开工时先定——不能和"状态账只记事实"的边界（D-0015）打架）；
5. **操作就近**：当前槽位高亮，裁定点 / 卡点（代填 / 作废）/ 状态上报贴着对应席位出现，
   不再让说书人在左栏与右栏表格之间来回找；
6. **数据面板下钻**：现有表格（状态账 / 效果链 / 两本账 / 最近变化）保留为可展开的"数据与审计"面板，
   与主视图同源，不删除；
7. **玩家端不动**：玩家端继续只有自己的席位 + 阶段 + 请求 + 信息（D-0013 §5 / D-0012 §4.3）；
   魔典视图是**说书人专用**；
8. **响应式与可达性**：大屏优先；小屏退化为按席位的纵向列表；键盘可达、对比度达标。

## 不做（本票边界）

- 投票记录 / 投票流程（平台尚无该能力；示例图的 [V] 菜单只作参考）；
- 玩家昵称（当前只有席位号；"玩家身份 / 昵称"是否引入另立票）；
- 音效 / 动画 / 官方美术风格复刻（本票解决"信息怎么摆"，不解决"美术怎么演"）；
- 规则内核与投影口径的任何改动。

## 决定与依据

- 玩家端信息隔离：D-0013 §5、D-0012 §4.3（魔典只说书人可见）；
- 呈现层不判规则：`web/AGENTS.md` §4；
- 不提交官方美术资源：`AGENTS.md`；
- 状态账边界（只记事实与归因，不替引擎翻转维度）：D-0015；
- 术语：`docs/standard/terminology.md`（魔典 / 提示标记 / 帷幕标记 / 席位 / 存活 / 死亡）。

## 架构审视结论（2026-10-02）

审视全文与运行时对应关系见 `docs/architecture/storyteller-presentation.md`；结论：

- 主视图容器 = **席位圆环**，席位顺序 = 服务端席位号（1 号在正上方、顺时针）；**不做拖拽重排**——
  顺序一旦可变就出现"本地顺序"这个第二事实来源，本票也没有任何规则需要它；
- 选中态是本地呈现态（默认跟随当前卡点 / 待裁定 / 当前槽位的归属席位）；主视图与下钻表格用**同一份**视图，不新增服务端契约；
- **提示标记只从事实派生**：中毒 / 醉酒 / 疯狂要求（R-0003）+ 该席全部效果链接（含已终止，终止态另标）；
  阵营用牌圈颜色 + 文案呈现。自由文本注记经需求方 2026-10-02 确认 **另立票据**（`todo/storyteller-annotation.md`），
  避免与 D-0015 冲突；两处口径边界如实记录：**角色变更不单列标记**（牌面即当前角色，变更史在下钻"最近变化"里查）、
  **效果"挂起"态当前投影不可区分**（`EffectDto` 只有 `terminated`；区分挂起属投影口径变更，不在本票）；
- 玩家名条只显示席位号：玩家昵称本票不做（见上"不做"清单）；
- 数据与审计（当前步骤 / 状态账 / 最近变化 / 效果链 / 两本账）收进可展开面板，**默认收拢**；
- 小屏退化为纵向席位列表；图形全部 CSS 自绘 + 文字，不引入位图素材；
- D-0018 的呈现边界**不修订**（仍是单 SPA 两套视图，玩家侧门禁不变）。

**独立对抗性复核（只读子代理，2026-10-02）**：4 项真实缺陷已在本轮修复并留运行时证据——

1. 换席只清勾选、不清取值（会把上一席的值静默写成下一席的事实）→ 整表复位 + 受理后复位，
   新增 `H-1 回归` 断言（换席后 select 回到「未选择」、勾选清空）；
2. 上报表单目标席位随视图推送漂移 → 表单 `focusin` 即锁定目标席位（`engage`）；
3. 勾选维度但没选取值 → 服务端"受理却静默丢维度" → 四个枚举加占位项 + 提交前本地校验，
   新增 `M-2 回归` 断言（本地拒绝、无序号、不发命令）；
4. 牌面标记渲染整段来由（牌面被撑爆）→ 标记只显示"是什么"，来由进 `title` 与操作台。

同轮加固装置：行 1 改为"席位号集合逐一比对"、行 2 改为"点非默认席并断言操作台跟随"。
复核另两点经核实不成立 / 按设计保留：玩家侧隔离**已有硬门禁**
（`PlayerProjectionLeakGateTests.PlayerSources_ImportOnlyPlayerSideModules` 白名单）；
卡点 / 裁定块"始终可见"是有意设计（兜底入口不被选中态挡住），已补"定位到该席"入口并同步文档口径。

**边界（如实记录）**：

- 效果"挂起"态当前投影不可区分（`EffectDto` 只有 `terminated`）；区分需改投影口径，不在本票；
- "角色变更"不单列标记：牌面即当前角色，变更史在下钻「最近状态变化」里查；
- 玩家昵称与自由文本注记不在本票（后者另立 `todo/storyteller-annotation.md`）。
