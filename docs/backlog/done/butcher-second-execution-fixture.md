## 要解决的问题

E34 残余：屠夫额外提名的**落靶**路径（额外提名收票达线 → 二次处决）目前只有内核
（`ButcherWindowTests`）与集成（`ButcherHostTests`）证据；主装置走的是「1 票不落靶 → 无二次处决」，
当时刻意避免为取证在真机里制造第二次处决打翻后续夜晚剧情。缺的是「额外提名真的把目标处决掉」
这条真机链路，以及它对当日处决账 / 窗口账的收口。

## 决定与依据

- 口径：R-0050（额外提名窗口）、《处决》第 5 步（触发屠夫能力，或立即结束白天）。
- 夹具优先独立装置 / 独立一局：主装置 day1 之后的夜晚剧情依赖既定存活名单，
  不能为落靶路径在既有流程里补一次真实处决。
- 装置设计：5 席固定角色（1 钟表匠 / 2 筑梦师 / 3 艺术家 / 4 呆瓜 / 5 诺-达希）+ 白天加入屠夫（第 6 席）；
  首夜只结清钟表匠裁定并把筑梦师请求强制作废（与落靶路径无关），两轮收票都用 3 票
  （6 席存活 → 3 票达线；5 席存活 → 3 票达线，不比前次多）。
