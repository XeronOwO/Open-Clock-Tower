# 整局端到端验收：说书人和玩家能不能真的玩完一局

- Status: Done（批次 E45，2026-10-05：验收矩阵 **12 行逐行判定全部通过**；新装置
  `tools/verify-full-game.mjs` 取证档 **49 项全过 · 107.2s**，票由本批一次会话判完；
  本批做过一次**独立对抗性复核**，其结论已逐条落到装置与本文里）
- Priority: High
- Depends on: 本人角色出口（`done/player-own-character.md`）——玩家不知道自己的角色时，
  "玩家这一侧"没有可判的对象

## 要解决的问题

`docs/acceptance/AGENTS.md` 开篇把验收与测试分开，问的就是这一句：**说书人和玩家能不能真的玩完一局？**
在此之前，平台**从来没有一次性回答过它**：主装置 `verify-storyteller-panel.mjs` 全程保持恶魔存活、
从不产生 `GameEndedEvent`（`docs/acceptance/devices.md` §1 的分工），胜负装置 `verify-winloss.mjs`
从「呆瓜被处决」一跳进结束面、夜里靠强制作废收场——两条链路各自成立，但"从头玩到尾"这件事
只能靠读者自己把十几份证据拼起来。本票把它变成一次会话的**逐行判定**。

## 装置：`tools/verify-full-game.mjs`

- **一次会话**：真宿主（独立临时库）+ 真 Vite + 1 个说书人页面 + **5 个玩家页面**（每席一个浏览器上下文）；
- **夜里的驱动器**（`driveNight`）轮询"说书人裁定点"与"哪一席挂着请求"，按剧本作答：
  筑梦师选恶魔、恶魔选剧本目标，**其余上下文一律记成计划外并让该行变红**（不猜、不放过）；
- **完成判据**是「开白天」按钮转为可用（与 `verify-butcher.mjs` 同口径，不依赖数据抽屉），
  抽屉里的「本计划已走完」作二次确认；
- **裁定点只记 `Accepted`**：被拒的记进 `decisionFailures` 并让该行红；同一条裁定连续被拒 3 次即停手
  （不靠等满超时收场）；
- **槽位读数与耗时**：每夜读状态条「槽位 k / N」并测墙钟耗时，断言"耗时 ≥ 槽位数 × 配额 × 0.5"
  ——「按配额推进」因此是**读数**，不是推论；
- 复盘读取等首屏到位（首跑踩到"加载中…"被当成结果——已修）。

**成本**：迭代档实测见 `docs/acceptance/devices.md` §2；取证档 **107.2s**——两个夜晚合计
**39 个槽位**（第 1 夜 14 + 第 2 夜 25）× 2s/槽 ≈ **78s** 是固定开销，其余是 2 个白天各一轮收票
与两次页面往返。

**它与其他装置的分工**（`docs/acceptance/devices.md` §1）：主装置跑通用玩法回归但不结束，
胜负装置跑呆瓜结束链路但夜里强制作废，本装置跑**没有任何夹具特权的一整局**。

## 残余与边界（登记，不在本票范围）

1. **只走了一条结束条件，而且善良路线在本夹具下结构上不可能出现**：本局以「除旅行者外仅剩两名存活
   → 邪恶获胜」收场；恶魔全程在座、从不是处决目标，所以"处决恶魔 / 恶魔清零"这条善良路线**不是
   "别处覆盖了"，而是本装置跑到不了**。善良路线的真机证据仍只在 `verify-winloss.mjs` 的呆瓜链路里；
   涡流「黄昏无人被处决」是集成用例级证据。
2. **只跑快乐路径 + 一次结束态拒绝**：整局里没有任何一次"合法作答被服务端拒绝"、没有掉线、
   没有请求超时、没有空槽位卡住。失败路径的证据在主装置的强推 / 作废段与集成用例里，不在本装置。
3. **投票阈值只覆盖两个达线点**（5 席存活 3 票、3 席存活 2 票）：**未达线（阈值 −1）、平票、
   重复提名同一人、死亡玩家最后一票**都没有在本装置里出现。
4. **反方向断言只做了一部分**：判了"处决的公开事实推到别人设备"（正向）与"公告不含角色名 / slug"
   （死因不外泄），但**没有**判"处决之前无关席位的 `player-executed` 为空"这类前置阴性对照。
5. **两名信息角色是否被常驻中毒，本装置不判**：恶魔坐 3 号、两侧最近的镇民是 1 / 5 号，按百科
   《诺-达鲺》· 2026-10-04 抓取 · 角色简介 / 运作方式 / 提示标记（"顺时针和逆时针方向上最近的镇民
   中毒……会跳过与他相邻的非镇民角色"）它们应当中毒；装置只如实记录"两次信息裁定走的都是
   **自由文本**分支"（与"能力未生效"一致），**没有**中毒态读数——"中毒者照常被唤醒 + 信息仍由
   说书人裁定"这件事的证据在 `verify-storyteller-panel.mjs` 与规则 / 集成用例里，不在本装置。
6. **席位固定 5 席**：6 席以上的投票阈值、旅行者参与白天流派的组合不在本装置覆盖。
7. **复盘只判"能开、能走步"**：复盘规模与翻页性能的采样在 `verify-replay-scale.mjs`。
