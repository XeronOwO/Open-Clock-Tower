# 角色变更装置：复盘里找不到「恶魔击杀」与「换手」两步

- Status: Todo
- Priority: **Medium**（**本批之前就红**：可能是某次批量改动让复盘步骤变少，也可能只是装置的走法过期；
  两种都值得查清，因为它问的是"复盘里看不看得见这一夜发生了什么"）
- Depends on: 无

## 要解决的问题

`tools/verify-character-change.mjs` 的第 10 段（说书人实时复盘五类标记）有两条断言找不到目标步骤：

```
[FAIL] 复盘逐步回放到「恶魔击杀」标记步骤 → 第 52 / 52 步 · 事件序号 228
[FAIL] 复盘逐步回放到「换手」标记步骤   → 第 52 / 52 步 · 事件序号 228
```

装置把复盘从第 1 步走到最后一步（总步数 **52**）都没等到这两个标记；同一批里的
「醉酒」「换角」「中毒」三步都找得到。按脚本头部的场景说明，第三夜应当有
"新方古（5 号）击杀理发师（4 号）"这一步（红色箭头）与理发师之夜的「换手」交互。

## 归因证据（2026-10-07，批次 E60 收尾总跑时咬出）

- 在**本批之前的 HEAD（`8ba2776`）**上跑同一装置：`失败 2 / 80`，**同两条、同一步数、同一序号**；
- 在本批的工作树上连跑两次：同样两条（序号 225 / 228 两次略有不同，是夹具节拍导致的步数差异）。
  ⇒ **与本批无关**，是更早的批次留下的；装置上一次被改动是 E48（入场重做）。

## 要查的两件事（按顺序）

1. **复盘是不是真的少了这两步**：若少，那是产品面的回归——某次改动让"恶魔击杀箭头"或
   "今晚理发换手"不再进复盘步骤目录（`ReplayStepCatalog` 的覆盖率门禁只管"事件类型有没有人认领"，
   管不了"这个场景里到底有没有那条事件"）。此时**先修产品**，再让装置跟着走。
2. **若复盘里本就没有这两步**（脚本的场景与夹具在这两条断言之后又改过）：那时才改装置，
   并且要写清"为什么这个场景不再产生这两步"——不许把断言删掉了事。
