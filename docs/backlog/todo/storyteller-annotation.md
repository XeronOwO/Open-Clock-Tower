# 说书人注记：魔典上的自由文本提示标记

- Status: Todo
- Priority: Low
- Depends on: 魔典主视图（`todo/grimoire-view.md`）；状态账边界 D-0015

## 要解决的问题

官方魔典允许说书人在席位旁挂**自由文本**提示标记（示例：「18 不共边」）。2026-10-02 需求方确认：
魔典首版只做**由事实派生**的提示标记（疯狂要求、生效中的效果链接），自由文本注记**另立本票**——
它不是游戏状态事实，混进状态账会违反 D-0015（账本只记事实与归因）。

## 待定（开工前必须回答）

1. **归属**：注记属于"这一局"还是"说书人的这块屏"？只有说书人能写吗？玩家是否可能看见？
2. **持久化**：进事件流（可回放 / 可撤销 / 重连可见）还是独立于事件流的旁路存储？重启后要不要还在？
3. **边界**：注记不得参与任何规则判定、不得进玩家投影；增删改要不要留审计；
4. **呈现**：挂在哪一席旁、超长文本怎么有界化、断线重连后怎么补齐（D-0010 的补全路径）。

## 验收矩阵

| # | 场景 | 期望 | 依据 |
|---|---|---|---|
| 1 | 说书人给某席加一条注记 | 该席牌面出现自由文本 token，状态账不受影响 | D-0015 |
| 2 | 注记含超长 / 换行 / 控制字符 | 有界化显示，不撑爆牌面 | 架构 §4.4 |
| 3 | 无关玩家视图 | 零下发、零活动（反方向断言） | D-0012 §4.3 / D-0013 §5 |
| 4 | 重连 / 重启 | 按第 2 条的待定结论决定"是否还在"，并留证 | D-0010 |

## 决定与依据

- 2026-10-02 需求方决定：首版不做，另立本票（魔典先交付派生标记）；
- D-0015：状态账只记事实与归因，自由文本不能混入；
- 术语：提示标记 `reminder-token`（`docs/standard/terminology.md`）。
