## 要解决的问题

2026-10-04 做裁定复核时发现：`git log` 提交时间与外部服务器时间（钟楼百科 `Date` 响应头）都指向
**2026-10-04**，但若干文档记录写 **2026-10-05**，例如：

- `docs/acceptance/batches.md`（E31 / E32 批次）；

用真实日期（2026-10-04），没有擅自改历史记录——需要一次统一核查：要么全部修正，要么说明成因后保留。
