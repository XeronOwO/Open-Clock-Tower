### 理发师（定稿）

**平台落地口径**（三条为项目自定，登记在案）：

1. **死亡触发 → 当夜交互**：死亡事件落账时**立即**记「今晚理发」事实（机制 2 的前半句）；与恶魔的交互发生在**当夜顺序表的理发师格**——那一格进入时由事件触发族向恶魔开操作请求。
2. **事实载体与生命周期**：机器级事实 `BarberNight`（与 `PitHagNight` 同族）：白天 → 夜晚跨阶段保留；夜晚 → 白天边界**清空并显式记录**「过时不候」（当前剧本内的死亡都发生在理发师格之前，此分支属登记在案的平台口径，不是静默默认）。
3. **选择形态**：一次原子选择 = 合法玩家对 + 「不交换」；候选对过滤「另一名恶魔」；可选自己与已死亡玩家；两名以上存活恶魔时由说书人先裁定用哪名恶魔，再向他开请求（机制 4）。

### 方古（定稿）

**平台落地口径**（登记在案，见 `rulings.md` R-0034 / R-0035）：

1. **侵染 = 同批两条状态变化**：目标角色 + 阵营（邪恶）一条、原方古死亡一条，外加「限一次」整局事实事件；
   被攻击的外来者**不产生死亡事实**。
2. **「限一次」是整局事实**（步骤机状态，跨阶段保留）：重放只折事件；原方古死亡 / 换角、之后又出现新的方古，
   都不得再侵染。
3. **麻脸巫婆之夜窗口**：侵染类攻击记为**携带转化载荷的待定死亡**——说书人「确认」= 转化，
   「阻止」= 击杀与转化都不发生；窗口收口的默认结果同样是转化；确认时目标已死亡 → 整体不发生。
4. **角色唯一只约束存活持有者**：侵染造成「已死亡原方古 + 存活新方古」两个同名标记，
   建表格绑给存活者；两名存活持有者才是数据缺陷。
5. **`[+1 外来者]`（阵型修正）**：平台不建盲抽袋、不做分布校验，以花名册数据 + 分配界面提示承载。

### 哲学家（定稿）

**平台落地口径**（登记在案，见 `rulings.md` R-0036）：

1. **获得能力 = 账上一条常驻标记效果**（带被获得的角色），**不写角色维度**（不变身）；整局保留，
   哲学家死亡 / 换角时终止。
2. **每局限一次由使用账本兜底**：醉酒 / 中毒期间的选择「机会被浪费」，之后不再给第二次选择。
3. **醉酒走常驻来源动态对账**：目标 = 被选角色的当前持有者（优先存活），随持有者变化**移动**；
   哲学家醉酒 / 中毒时挂起、死亡 / 换角时终止。
4. **执行落格**（与规则原文时机的偏差登记在案）：被选角色的格没有行动者时由哲学家**代行**（选择当夜
   尚未进入就地激活，首夜能力当夜可用）；那一格有持有者时它仍归持有者（醉酒 → 不生效、照常被唤醒），
   哲学家改在**自己的格**上代行；触发型 / 不在本阶段表上的能力本夜无行动并留跳过记录。
5. **归因**：代行槽位的能力名记被获得角色（使用 / 失效账本记在它名下），行动者席位是哲学家。

## 决定与依据

- 机制地基与口径继承麻脸巫婆票（`done/pit-hag-character-change.md`）；本票只补各角色自己的规则。
- 规则细节按钟楼百科**逐页核对**并登记来源（见上表）；拿不准的登记 `rulings.md`，不许凭记忆。
- **新裁定**：
  - **R-0031** 舞蛇人交换后的永久中毒：来源 = 被换者本人；不随本人醉酒 / 中毒挂起，只随该角色死亡 / 离场终止
    （提示标记的唯一移除时机；自指会令维度对账无法收敛）。实现为 `PersistentEffect.SourceStateIndependent`。
  - **R-0032** 角色在夜里换手后，尚未进入的槽位跟随新持有者（行动者与提示按新持有者重建，
    以 `SlotActivatedEvent` 进事件流；已进入的槽位不重绑）。
  - **R-0034** 方古侵染与麻脸巫婆之夜「死亡裁量窗口」的交互：待定死亡携带转化载荷；说书人「确认」= 按能力转化、
    「阻止」= 击杀与转化都不发生；确认时目标已死 → 整体不发生；「限一次」是整局事实；
    角色唯一只约束**存活**持有者（已死亡的原方古标记仍留在魔典上）。
  - **R-0035** 阵型修正（`[+1 外来者]`）在平台上的承载：花名册数据 + 开局分配界面提示；
    平台不建盲抽袋、不做分布校验（人数-分布表校验属独立能力，须另立票据）。
  - **R-0036** 哲学家「获得能力」的落法：账上一条带 `GrantedCharacter` 的常驻事实（不变身）；每局限一次
    由使用账本兜底（醉酒 / 中毒期间的选择算浪费）；被选角色持有者的**常驻醉酒**动态对账（随持有者移动、
    随哲学家状态挂起 / 终止）；能力执行落格 = 被选角色的格没有行动者时由获得者代行、否则在自己的格上代行。
- **不新增信息结果**：舞蛇人选到非恶魔时，「得知对方不是恶魔」是行动仪式本身的隐含事实，
  不是由说书人裁定的信息（本角色不属于「获取信息」类）——不产 `InformationResultIssuedEvent`。
- **本人得知边界**：角色 / 阵营变化对本人告知沿用开局分配的口径（说书人外部语音）；
  玩家投影的角色出口是既有残余（`done/settlement-engine.md` 残余 3「随玩家端票据」），本票不扩大投影面，
  只保证无关玩家零泄漏与说书人可见。
- 家族通用行的「阵营不变」修正见上（舞蛇人 / 方古为百科明文例外）。
